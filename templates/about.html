🗳️ About Online Voting System

A simple, secure and user-friendly voting management system.

📌 About the Project

The Online Voting System is a web-based project developed to manage voter information and voting records in an organized way.

The system provides a simple interface for adding, viewing, searching, editing and deleting voter records.

✨ Key Features

  • 🔐 Login and registration system
  • ➕ Add voter information
  • 📋 View voter records
  • 🔎 Search voter records
  • ✏️ Edit voter records
  • 🗑️ Delete voter records

💻 Technologies Used

This project is built using the following technologies.

Python Flask HTML Bootstrap SQLite

🎯 Project Goal

To provide a simple and organized platform for managing voter information and voting records.

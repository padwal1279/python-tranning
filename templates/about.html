🗳️ About Online Voting System

A simple and user-friendly voting management project.

📌 About the Project

This project is a simple Online Voting System developed using Python, Flask, HTML, Bootstrap and SQLite.

It is designed to manage voter information and voting records in an easy and organized way.

✨ Features

  • Add voter and vote information
  • View voter records
  • Edit voter records
  • Delete voter records
  • Simple and responsive interface

💻 Technologies Used

Python Flask HTML Bootstrap SQLite
